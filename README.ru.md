# Драйвер PCA9685 (I2C) для STM32 — управление сервоприводами

🇬🇧 [English version — README.md](README.md)

Лёгкий платформонезависимый драйвер на C для 16-канального 12-битного ШИМ-контроллера NXP **PCA9685** с интерфейсом I2C. Чаще всего используется для управления 16 сервоприводами (или светодиодами) от STM32 по двум проводам I2C.

Логика драйвера (`pca9685_i2c.c/.h`) отделена от аппаратного слоя (`pca9685_i2c_hal.c/.h`). В комплекте есть реализация для STM32 HAL. Для переноса на другой МК достаточно заменить HAL-файл.

Полный справочник по API с таблицами находится в [README.md](README.md#api-reference). Ниже — краткое изложение на русском.

## Возможности

- Полный доступ к регистрам MODE1/MODE2, суб-адресам и All-Call.
- Скважность и фазовая задержка задаются в процентах (0.0–100.0 %).
- Простая настройка частоты через PRE_SCALE (например, 50 Гц для сервоприводов).
- Режимы сна, пробуждения и перезапуска (restart).
- Готовая реализация для STM32 HAL (дескриптор `hi2c1`).

## Подключение

```
 STM32                    Плата PCA9685                 Питание сервоприводов
 3V3  ─────────────────── VCC   (логика, 2.3–5.5 В)
 GND  ─────────────────── GND ──────────────────────────── GND (–)
 I2C SCL (напр. PB6/PB8) ─ SCL
 I2C SDA (напр. PB7/PB9) ─ SDA
 GPIO (по желанию) ─────── OE    (активный НИЗКИЙ)
                          V+    ─────────────────────────── +5…6 В (+)
```

- **SCL/SDA** подключаются к выводам выбранного в CubeMX I2C. Типичные варианты для F1/F4: PB6/PB7 или PB8/PB9. На Nucleo-64 разъём Arduino D15/D14 — это PB8/PB9.
- **Подтягивающие резисторы** на SDA и SCL обязательны. На большинстве модулей PCA9685 уже стоят 10 кОм к VCC. Если их нет, поставьте 2.2–4.7 кОм к 3.3 В. Внутренних подтяжек STM32 (~40 кОм) недостаточно.
- **VCC и V+ — разные цепи.**
  - **VCC** питает логику. Подавайте 3.3 В от STM32, тогда и шина I2C подтянута к 3.3 В. Если VCC = 5 В, проверьте, что выводы SDA/SCL толерантны к 5 В (FT).
  - **V+** питает только сами сервоприводы. Нужен **отдельный** источник 5–6 В, рассчитанный на пусковые токи (≈1 А и более на сервопривод). **Не питайте** сервоприводы от 5 В ST-Link/Nucleo или USB.
  - Поставьте конденсатор 470–1000 мкФ между V+ и GND рядом с платой.
- **Общая земля обязательна**: GND у STM32, PCA9685 и блока питания сервоприводов должен быть соединён.
- **OE** — активный низкий уровень. На модулях он подтянут к GND, поэтому без подключения выходы включены. Если подключаете OE к GPIO, держите его в «1» до окончания настройки, а затем переведите в «0»: так сервоприводы не дёргаются при включении.
- **Адрес**: перемычки A0–A5 разомкнуты — 0x40. Каждая замкнутая перемычка добавляет 1/2/4/8/16/32, итого 0x40–0x7F. Не используйте 0x70 — это адрес All-Call по умолчанию.

## Настройка в STM32CubeMX / CubeIDE

1. *Connectivity → I2C1* → Mode: **I2C**.
2. *I2C Speed Mode*: **Standard (100 кГц)** — самый надёжный вариант. **Fast (400 кГц)** подходит при коротких проводах.
3. В *GPIO Settings* проверьте, что SCL/SDA назначены на нужные выводы (Alternate Function Open Drain).
4. (По желанию) Настройте GPIO для OE: Output, начальный уровень High.
5. Сгенерируйте код. Будет создан `I2C_HandleTypeDef hi2c1;` и вызов `MX_I2C1_Init()`.
6. Скопируйте `.c` файлы в `Core/Src`, а `.h` файлы в `Core/Inc`.
7. Если используется не I2C1, замените `hi2c1` на свой дескриптор в `pca9685_i2c_hal.c`.
8. Ошибка `undefined reference to 'round'` означает, что не подключена библиотека `m` (линкер, `-lm`).
9. Вызывайте функции драйвера **после** `MX_I2C1_Init()`.

## Минимальный пример

```c
#include "pca9685_i2c.h"

pca9685_dev_t pca9685;

void setup_pca9685(void)
{
    pca9685_i2c_hal_init();          // проверка, что hi2c1 инициализирован
    pca9685_i2c_reset();             // сброс ДО register(), иначе адреса сбросятся

    pca9685_i2c_register(&pca9685, I2C_ADDRESS_PCA9685,
                                   I2C_ALL_CALL_ADDRESS_PCA9685,
                                   I2C_SUB_ADDRESS_1_PCA9685,
                                   I2C_SUB_ADDRESS_2_PCA9685,
                                   I2C_SUB_ADDRESS_3_PCA9685);

    // ОБЯЗАТЕЛЬНО: led_pwm_set пишет 4 регистра за одну транзакцию
    pca9685_i2c_autoincrement(pca9685, PCA9685_AUTOINCR_ON);

    // Частоту можно менять только в режиме сна
    pca9685_i2c_sleep_mode(pca9685, PCA9685_MODE_SLEEP);
    pca9685_i2c_write_pre_scale(pca9685, 50.0, 25000000);
    pca9685_i2c_sleep_mode(pca9685, PCA9685_MODE_NORMAL);
    pca9685_i2c_restart(pca9685);

    pca9685_output_t out = {
        .outdrv = PCA9685_OUTPUT_TOTEM_POLE,
        .outne  = PCA9685_OUTPUT_LOW,
        .och    = PCA9685_CH_ONSTOP,
        .invrt  = PCA9685_OUTPUT_NOTINVERT,
    };
    pca9685_i2c_output_init(pca9685, out);
}

void servo_center(void)
{
    // 7.5 % при 50 Гц = импульс 1.5 мс = среднее положение
    pca9685_i2c_led_pwm_set(pca9685, 0, 7.5f, 0.0f);
}
```

`pca9685_i2c_register()` принимает **указатель** (`&pca9685`). Все остальные функции принимают структуру **по значению**.

**Импульс → скважность при 50 Гц** (период 20 мс): 1.0 мс = 5 %, 1.5 мс = 7.5 %, 2.0 мс = 10 %. Шаг ШИМ ≈ 4.9 мкс.

## Краткий справочник API

Функции возвращают `PCA9685_OK` (0) при успехе. При ошибке возвращается ненулевое значение (`PCA9685_ERR` = −1; функции из нескольких транзакций могут вернуть сумму ошибок, поэтому проверяйте `!= PCA9685_OK`).

| Функция | Назначение |
|---------|-----------|
| `pca9685_i2c_register(&dev, addr, allcall, sub1, sub2, sub3)` | Заполняет структуру и записывает в чип адреса All-Call и суб-адреса. Ничего не возвращает (`void`). |
| `pca9685_i2c_reset()` | Программный сброс (SWRST через General Call 0x00) **всех** PCA9685 на шине. После сброса: сон, автоинкремент выключен. |
| `pca9685_i2c_sleep_mode(dev, PCA9685_MODE_SLEEP / _NORMAL)` | Выключает или включает генератор. |
| `pca9685_i2c_restart(dev)` | Перезапуск ШИМ после пробуждения. |
| `pca9685_i2c_clock(dev, PCA9685_CLK_INTERNAL / _EXTERNAL)` | Источник тактирования (внешний — только в режиме сна; сбрасывается лишь сбросом или выключением питания). |
| `pca9685_i2c_autoincrement(dev, PCA9685_AUTOINCR_ON / _OFF)` | Автоинкремент регистров. **Нужен** для всех функций `*_led_*`. |
| `pca9685_i2c_output_init(dev, pca9685_output_t)` | Настройка MODE2: тип выхода, инверсия, момент обновления, состояние при OE = 1. |
| `pca9685_i2c_read_mode_1/2(dev, &val)` | Чтение регистров MODE1/MODE2. |
| `pca9685_i2c_write_pre_scale(dev, freq, osc_hz)` | Установка частоты (≈24–1526 Гц при 25 МГц). Только в режиме сна. |
| `pca9685_i2c_read_pre_scale(dev, &freq, osc_hz)` | Чтение текущей частоты. |
| `pca9685_i2c_led_pwm_set(dev, ch, duty%, delay%)` | ШИМ на канале 0–15. Соблюдайте условие `duty + delay ≤ 100`. |
| `pca9685_i2c_all_led_pwm_set(dev, duty%, delay%)` | ШИМ на всех каналах. В текущей реализации возвращает ошибку при `delay = 0`. |
| `pca9685_i2c_led_set(dev, ch, PCA9685_LED_ON / _OFF)` | Канал полностью включён или выключен, без ШИМ. |
| `pca9685_i2c_all_led_set(dev, PCA9685_LED_ON / _OFF)` | То же для всех каналов. |
| `pca9685_i2c_write/read_allcall_addr(dev, ...)` | Запись и чтение адреса All-Call (7 бит). |
| `pca9685_i2c_allcall_address_resp(dev, PCA9685_ADDR_RESPOND / _NORESPOND)` | Включение и отключение ответа на All-Call. |
| `pca9685_i2c_write/read_sub_addr(dev, PCA9685_SUB_ADDR_n, ...)` | Запись и чтение суб-адресов 1–3. |
| `pca9685_i2c_sub_addr_resp(dev, PCA9685_SUB_ADDR_n, resp)` | Включение и отключение ответа на суб-адрес. |
| `pca9685_i2c_hal_init / _read / _write / _ms_delay` | Платформенный слой (для STM32 уже реализован). |

## Решение проблем

**Все функции возвращают ошибку**
- Неверный адрес. Передаётся **7-битный** адрес (0x40, а не 0x80). Проверьте перемычки A0–A5. Шину можно просканировать вызовом `HAL_I2C_IsDeviceReady(&hi2c1, addr << 1, 2, 10)` для `addr` от 0x03 до 0x77.
- Не вызван `MX_I2C1_Init()`, или в `pca9685_i2c_hal.c` указан не тот дескриптор.
- Перепутаны SDA и SCL, нет подтяжек или не подано питание VCC (одного V+ недостаточно).

**I2C работает, но сервоприводы стоят**
- Не включён автоинкремент: вызовите `pca9685_i2c_autoincrement(dev, PCA9685_AUTOINCR_ON)`.
- Чип остался в режиме сна после сброса: вызовите `sleep_mode(..., PCA9685_MODE_NORMAL)` и `restart()`.
- На OE высокий уровень.
- Нет питания V+ или нет общей земли.

**Дрожание, рывки, перезагрузка МК**
- Слабый блок питания или тонкие провода. Используйте отдельный источник 5–6 В и конденсатор 470–1000 мкФ.
- МК перезагружается — сервоприводы питаются от той же линии 5 В, что и МК. Разделите питание, оставив общей только землю.
- Импульс выходит за пределы диапазона сервопривода. Держитесь в пределах 1.0–2.0 мс (5–10 %).
- Неточная частота: внутренний генератор лишь приблизительно 25 МГц. Измерьте период осциллографом и передайте скорректированное `osc_clk_hz` (например, 26000000, если вместо 50 Гц получилось 52 Гц).
- Длинные сигнальные провода рядом с силовыми. Укоротите их или скрутите каждый с GND.

**Рывок сервопривода при включении**
- Управляйте OE через GPIO: держите «1», пока ШИМ не настроен, затем выставьте «0».

## Перенос на другие платформы

Реализуйте 4 функции в `pca9685_i2c_hal.c`: `pca9685_i2c_hal_init()`, `pca9685_i2c_hal_read()`, `pca9685_i2c_hal_write()` и `pca9685_i2c_hal_ms_delay()`. Подробности — в [README.md](README.md#porting-to-other-platforms).
